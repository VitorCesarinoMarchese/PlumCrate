# Native mod library

Mode: Operate. User-approved direction: Plumbob, chosen from five HTML concepts and implemented in native egui. The concept reference is `/home/tept/.codex/artifacts/ts4-design-previews/concept-1.html`; actual Rust widgets define behavior. [DESIGN.md](../../DESIGN.md) is the canonical visual guide.

Your mods leads with actual library counts and the blue Add mods menu for folder/ZIP imports. A fixed 240-point blue rail at widths of at least 900 points holds Your mods, Discover, Updates, Trash and Settings. Narrow windows use compact top navigation with Trash in the header. The slogan hides in short windows. Search, All/On/Off filters and icon card/list controls preserve selected identity.

Cards show real previews and metadata. Their photo region is 140 points above a 98-point information/footer region, or 88 points without saved previews. Under 220 points of available content height the library temporarily renders compact list rows without changing the view preference. Rows normally use 64-point height, 44-point previews and 10-point vertical padding. Below 64 points of available list height they use 40-point height, 32-point previews and 4-point vertical padding, keeping the full switch visible above footer notices. Selecting a card or row opens the existing centered mod details popup at every width. Right-click selects the clicked identity before showing shared actions. Cards and list rows share direct On/Off switches using Action::Toggle { enabled }. A switch click opens neither details nor a review; failures remain visible in the bottom status. Core locking, ownership and collision checks, and journaling remain in place. Folder and ZIP imports enable in the selected game by default. An enable conflict keeps the imported library content and unrelated game files, and shows a warning without offering another import.

The light default uses pale blue panels, white cards and green selection accents; the dark counterpart uses navy. Saved themes and custom light/dark palettes remain intact. The original plumbob SVG and authored compass supply identity. Mod photography comes from real user/provider content, never generated bundled photos.

Updates retains manual checks of explicitly attached CurseForge projects. The actual library summary's Review opens Updates; Review beside a linked report opens mod details. Checks never download or replace files. Recording an installed release requires confirmation and writes metadata only. Browser-assisted installations retain their existing release, source, folder and game-destination review; approval covers verified import and enabling. Desired dependencies require separate reviews. Source attachment never happens silently. Trash remains recoverable.

Settings keeps Plumbob controls and navigation, with Appearance, Folders, Connections, App updates and Backup tabs. Pinned Save changes and Discard changes actions accompany Saved or Not saved section status. Theme choices, edits, removal and imports stay in a draft until Save changes. A scoped production-widget preview has independent Light colors and Dark colors editors. Back and Escape preserve drafts; Discard reverses theme removal. Invalid hex colors and names prevent saving, while valid fills and accents remain intact and text adjusts against each painted background. Outside Settings, the header mode switch uses saved colors and preserves drafts; the switch hides in Settings. Local credential rules remain unchanged. Preview requests omit Referer; missing/broken local previews show No Preview, while broken provider images hide. Low-confidence source warnings remain visible. All management, provider and filesystem safety requirements remain in force.

Historical capture reports describe prior feature validation, not approval for file operations. Current Plumbob capture and full-validation results belong to the implementation report. The native egui app does not use the HTML/CSS detector.
