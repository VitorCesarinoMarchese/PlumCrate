# v0.0.1-alpha.1

The first public alpha of PlumCrate for Linux.

## Included

- Browse your local mods as photo cards or a list, with live search and On/Off filters.
- Import folders and ZIP archives, review existing mods for migration, and enable or disable managed mods individually or in bulk.
- Browse CurseForge projects, read descriptions and dependencies, and install verified browser downloads after choosing Download in browser.
- Attach sources after review and check attached projects for newer releases on request.
- Restore removed mods from Trash. Permanent deletion requires a verified app-owned bundle, a review, and acknowledgement that deletion cannot be undone.
- Use light, dark, or custom themes and save multiple game-folder locations.
- Check for AppImage updates, verify downloaded releases, and preserve the previous AppImage during installation.

## Download and run

Download `plumcrate-0.0.1-alpha.1-x86_64.AppImage` and its `.sha256` file to the same folder. In that folder, run:

```sh
sha256sum -c plumcrate-0.0.1-alpha.1-x86_64.AppImage.sha256
chmod +x plumcrate-0.0.1-alpha.1-x86_64.AppImage
./plumcrate-0.0.1-alpha.1-x86_64.AppImage
```

If FUSE is unavailable, run with extraction mode:

```sh
APPIMAGE_EXTRACT_AND_RUN=1 ./plumcrate-0.0.1-alpha.1-x86_64.AppImage
```

Choose the Sims 4 folder containing `Mods`. Start with a small collection and keep a backup of your game saves and mods while testing this alpha.

## Alpha limitations

- Linux x86_64 is the release target. Windows, macOS, and other architectures have not been verified.
- CurseForge browsing, source lookup, browser-assisted installation, and mod update checks require your own API key saved in local Settings. Local library management works without a key. Do not include keys in bug reports.
- Browser-assisted installation opens the provider's download page. Your browser may still require a Download or save click. Each dependency needs its own download action.
- Mod update checks do not automatically replace an older managed release. Download and replace it manually.
- Mods can require other mods or a particular game version. Read the author's instructions and dependency information.

Report bugs with your Linux distribution, desktop session, steps to reproduce, and expected behavior at https://github.com/VitorCesarinoMarchese/PlumCrate/issues. Remove API keys and private paths from screenshots and logs.
