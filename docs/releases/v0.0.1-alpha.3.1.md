# v0.0.1-alpha.3.1

This Linux alpha corrects the upgrade guidance for users of alpha.1. It includes the preview memory improvements and browser download cleanup from alpha.3. There is no updater runtime change in this release.

## Upgrade from alpha.1

Alpha.1 cannot discover current PlumCrate releases because its updater expects the asset and executable names used before the project rename. It reports no compatible update. Publishing a newer release cannot change that installed updater.

Close alpha.1 and manually download the AppImage below. Existing mods and settings remain in their current locations. This is a one-time manual upgrade. Alpha.2 and later use the PlumCrate names and can discover subsequent releases through **Settings → App updates**.

## Download and run

Download `plumcrate-0.0.1-alpha.3.1-x86_64.AppImage` and its `.sha256` file into the same folder, then run:

```sh
sha256sum -c plumcrate-0.0.1-alpha.3.1-x86_64.AppImage.sha256
chmod +x plumcrate-0.0.1-alpha.3.1-x86_64.AppImage
./plumcrate-0.0.1-alpha.3.1-x86_64.AppImage
```

If FUSE is unavailable, use extraction mode:

```sh
APPIMAGE_EXTRACT_AND_RUN=1 ./plumcrate-0.0.1-alpha.3.1-x86_64.AppImage
```

The updater preserves the installed AppImage's filename. After an in-app update, check the version in Settings rather than the filename.

## Included changes and requirements

- Preview images use bounded thumbnails and a shared local decoding worker. Original images stay unchanged.
- Successful browser-assisted installations close their separate browser window and move the verified source download to recoverable Trash.
- Automatic window closing requires native Chromium or Firefox. The isolated profile does not share your normal browser logins.

Linux x86_64 is the release target. CurseForge features require your own API key in local Settings. Keep backups while testing this alpha.

See the [alpha.3 notes](https://github.com/VitorCesarinoMarchese/PlumCrate/blob/main/docs/releases/v0.0.1-alpha.3.md) for the previous changes and limitations. Report problems at https://github.com/VitorCesarinoMarchese/PlumCrate/issues without API keys or private paths.
