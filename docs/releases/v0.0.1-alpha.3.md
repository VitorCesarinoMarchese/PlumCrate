# v0.0.1-alpha.3

This Linux alpha reduces memory used by mod previews and cleans up browser-assisted downloads after installation succeeds.

## Changes

- Preview images use thumbnails capped at 512 pixels on the longest edge. Local previews share a decoding worker, and the memory cache stays bounded when offscreen requests finish or images fail. Original image files stay unchanged.
- Browser-assisted installs open a separate Chromium or Firefox window with an isolated profile. PlumCrate closes that window after a successful installation. Cancelling an installation also closes its owned window and prevents delayed launches. Your normal browser tabs stay open.
- After installation succeeds, PlumCrate moves the verified source download to recoverable Trash. Cleanup preserves files that changed or were replaced. If Trash is unavailable, the download stays in place and Activity reports the cleanup problem without marking the installed mod as failed.

## Download and run

Download `plumcrate-0.0.1-alpha.3-x86_64.AppImage` and its `.sha256` file into the same folder, then run:

```sh
sha256sum -c plumcrate-0.0.1-alpha.3-x86_64.AppImage.sha256
chmod +x plumcrate-0.0.1-alpha.3-x86_64.AppImage
./plumcrate-0.0.1-alpha.3-x86_64.AppImage
```

If FUSE is unavailable, use extraction mode:

```sh
APPIMAGE_EXTRACT_AND_RUN=1 ./plumcrate-0.0.1-alpha.3-x86_64.AppImage
```

Existing mods and settings remain in their current locations. Alpha.2 builds can check for this release in **Settings → App updates**. Alpha.1 requires a one-time manual AppImage replacement because its updater expects the names used before the PlumCrate rename.

## Browser requirements and alpha limitations

Automatic window closing requires a native Chromium or Firefox installation. The isolated browser profile has its own session and does not share your usual logins. The provider's page may still require a Download or save click. Downloads use the folder selected in PlumCrate. Unsupported browsers and sandboxed installations may not work with this flow.

Linux x86_64 is the release target. CurseForge features require your own API key in local Settings. Keep backups while testing this alpha.

See the [first alpha notes](https://github.com/VitorCesarinoMarchese/PlumCrate/blob/main/docs/releases/v0.0.1-alpha.1.md) for the full feature list and other limitations. Report problems at https://github.com/VitorCesarinoMarchese/PlumCrate/issues without API keys or private paths.
