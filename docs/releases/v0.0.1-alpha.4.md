# v0.0.1-alpha.4

Browse the folders you already use to organize your Sims 4 mods. Choose **Browse files** in the library or **Browse folders** under **Details → Files**. Open a subfolder to see its files and use the breadcrumbs to go back.

Browsing is read-only. A rescan keeps the current folder open when it still exists and returns to the nearest surviving parent if it disappears.

[Folder browsing screenshots and implementation details](https://github.com/VitorCesarinoMarchese/PlumCrate/pull/2)

## Install or update

Download the Linux x86_64 AppImage and its checksum into the same folder.

```sh
sha256sum -c plumcrate-0.0.1-alpha.4-x86_64.AppImage.sha256
chmod +x plumcrate-0.0.1-alpha.4-x86_64.AppImage
./plumcrate-0.0.1-alpha.4-x86_64.AppImage
```

If FUSE is unavailable, run the AppImage with `APPIMAGE_EXTRACT_AND_RUN=1`.

Alpha.2 and later can check for the release under **Settings → App updates**. Alpha.1 requires a [one-time manual upgrade](v0.0.1-alpha.3.1.md). Existing mods and settings stay in their current locations.
